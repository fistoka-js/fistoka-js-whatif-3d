# Catalogue

_Generated by `node tools/catalog.mjs` from the code. Do not edit by hand._

## Props

Fields every prop has:

| field | type | what |
|---|---|---|
| `id` | text (up to 40 characters); required | unique id in this shot (a-z, 0-9, dashes) |
| `type` | text (up to 200 characters); required | which prop from the catalogue |
| `at` | place: a slot (center, left, right, top, bottom, top-left, top-right, bottom-left, bottom-right, front, back, far-left, far-right) or [x, y, z]; default "center" | where it stands |
| `size` | number 0.05..6; default 1 | size (1 = fits a unit box) |
| `rotate` | list of number -360..360; default [0,0,0] | turn [x, y, z] in degrees |
| `hidden` | true or false; default false | start hidden |

Props with stageSpace: true are drawn between their own points (from/to); they have no at, size or rotate, and cannot move, scale, spin, orbit, bob, shake or pulse.

## Camera

| field | type | what |
|---|---|---|
| `focus` | list of the id of a prop in this shot | prop ids to frame (default: all props) |
| `framing` | one of: close \| medium \| wide; default "medium" | how tight the shot is |
| `angle` | one of: front \| high \| low \| top \| side \| three-quarter; default "front" | where the camera looks from |
| `move` | one of: drift \| push_in \| pull_out \| orbit \| rise \| pan \| still; default "drift" | camera motion during the shot |
| `amount` | number 0..1; default 0.5 | strength of the move |

**angle**:

- `front`: straight on, a little above
- `high`: from above, looking down
- `low`: from below, looking up (heroic)
- `top`: almost straight down
- `side`: from the right side
- `three-quarter`: from the front-right, a little above

**move**:

- `drift`: slow small sideways float (default; never fully still)
- `push_in`: moves closer during the shot
- `pull_out`: moves away during the shot
- `orbit`: circles around the subject
- `rise`: cranes up, looking down more and more
- `pan`: slides sideways past the subject
- `still`: almost still (a tiny breathing motion)

Slots: `center` [0, 0, 0], `left` [-0.8, 0, 0], `right` [0.8, 0, 0], `top` [0, 0.9, 0], `bottom` [0, -0.9, 0], `top-left` [-0.8, 0.9, 0], `top-right` [0.8, 0.9, 0], `bottom-left` [-0.8, -0.9, 0], `bottom-right` [0.8, -0.9, 0], `front` [0, 0, 0.8], `back` [0, 0, -1.2], `far-left` [-1.6, 0, 0], `far-right` [1.6, 0, 0]

Colour names: red, orange, yellow, green, teal, cyan, blue, indigo, purple, pink, white, grey, black, brown, gold, accent (or #rrggbb).

Anchors: anchor: "spoken phrase" | {phrase, edge, offset} | {time} | {shot}

Transitions: `cut` hard cut (default); `dip` quick dip through the new shot's environment colour
